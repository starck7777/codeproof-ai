# Three-minute demo

0:00–0:30 — Open Overview. Explain complete agent workflows: source inspection, patch, tool budget, stopping and trusted evaluation. Point out the prominent Demo Replay label and missing model usage.

0:30–1:00 — Tasks: select Inclusive range. Show requirements, allowed source, task version and isolation limits. New Benchmark: select DirectPatch and IterativeFix, equal budgets, one repetition. Confirm configuration.

1:00–1:40 — Observe progress and tool events. Refresh once to show persisted snapshots. Docker runs public tests, then the repair loop ends and fresh evaluation runs trusted cases. If infrastructure is unavailable, state the blocker; never present a screenshot or empty page as completed evidence.

1:40–2:20 — Open DirectPatch evidence: inspect the +1 endpoint change and real evaluation counts. Open IterativeFix: starter retained intentionally, illustrating functional failure. Explain these are scripted outcomes, not superiority claims about agents/models.

2:20–2:45 — Compare sample sizes, success and missing usage. Explain infrastructure failures have a separate category and no-success cost efficiency is undefined. Configure a second run with one tool call to illustrate budget exhaustion; do not claim it passed tests.

2:45–3:00 — Download JSON/CSV/HTML evidence. Show methodology and limitations, then outline live Bifrost integration, stronger sandbox boundaries and larger uncontaminated tasks.
