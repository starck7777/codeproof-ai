# Eight-slide pitch outline

1. Problem — coding-agent comparisons often hide tool costs, retries and regressions; response quality alone misses workflow behavior.
2. Solution — CodeProof records edits, public feedback, budgets and trusted evaluation evidence.
3. Workflow — choose tasks → strategies/models → equal budgets → monitor → inspect diff → compare → export.
4. Architecture — React/FastAPI/PostgreSQL/Redis; trusted host worker and offline Docker; Bifrost provides model gateway calls with recorded usage.
5. Integrity — source-only patch export, protected paths, fresh evaluator, hidden feedback after repair ends, bounded resources; Docker has limitations.
6. Demonstrated results — insert only verified run IDs and exported counts after execution. Demo Replay examples are scripted, not live model quality. No measured results are asserted here.
7. Differentiation and limitations — traceable full workflows; original small Python suite, public-fixture contamination risk, local-only security model, limited comparison UI.
8. Next steps — complete full verification, broader tasks, multi-model sweeps, dedicated VM isolation, external artifacts and authenticated research workspaces.
